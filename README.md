# Peer Evaluation Rating Matrix Application

Full-stack Node.js + MySQL implementation of the Peer Evaluation Rating Matrix for group project assessment.

## Setup Instructions

1. Import `schema.sql` into your MySQL server.
2. Copy `.env.example` to `.env` and configure your database host, user, and password.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application server:
   ```bash
   npm start
   ```
5. Open your browser and navigate to `http://localhost:3000`.
